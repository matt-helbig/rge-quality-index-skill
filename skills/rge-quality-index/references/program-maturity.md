# Program context

Load only for a program audit or a multi-email review with actual journey context. A single email rarely establishes cadence, sequencing, segmentation, or revenue mix. Do not turn missing context into a program failure or invent it to avoid P5's 3.0 observability default.

## Campaign and flow balance

Use supplied reporting to understand how campaigns and automated journeys serve the business and audience. There is no universal target revenue split in this rubric. Check whether relevant recipient moments are served well, rather than rewarding a particular percentage of automated revenue.

## Sequence length and cadence

Evaluate the purpose and incremental value of each message, recipient control, and supplied engagement evidence. Neither a particular number of onboarding emails nor lower frequency is automatically better. Score the individual email on its own task; record program concerns separately unless they materially affect that task.

## Preference management

A visible preference-center link is evidence that a choice is offered, not proof that the destination functions or provides granular controls. Credit verified topic, frequency, or format choices when they serve the audience. Inspect without submitting changes to a recipient's preferences.

## Seasonal relevance

Brand-specific occasions and widely shared holidays can both be appropriate. Judge whether the occasion has an authentic connection to the message and audience. A program-level calendar claim requires calendar evidence; a single seasonal email only supports a judgment about that message.
